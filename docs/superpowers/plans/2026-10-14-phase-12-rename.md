# Phase 12: the rename to CapacityRoom — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every live name of the project becomes CapacityRoom or one of its fixed technical forms, released as 2.0.0.

**Architecture:** A rename in five sequential tasks, each a set of mechanical replacements with the tests that pin the new names written red first. The guard of the old name comes last, so that `make test` stays green between tasks, and it is seen failing on a mutation before the phase closes. No behaviour, number, query, schema, or layout changes, except the colophon sentence of the PDF.

**Tech Stack:** Go 1.27, React and TypeScript under `web/`, Typst 0.15.1, Docker Compose, GNU make, all inside `nix develop`.

**Spec:** `docs/superpowers/specs/2026-10-14-capacity-room-rename-design.md` (approved 2026-10-14, amended at 1c823b9). Read it before any task; it holds the name map this plan applies.

## Global Constraints

- Command, cmd folder, binary, images, Compose project: `capacity-room`.
- Go module: `github.com/marceloalvescf/capacity-room`. Root package: `capacityroom`.
- Environment variables: `CAPACITYROOM_` followed by the rest of the old name (`KCR_DATABASE_DSN` becomes `CAPACITYROOM_DATABASE_DSN`).
- Lowercase identifiers: `capacityroom_` or `capacityroom-` in place of `kcr_` or `kcr-`; `capacityroom.` in place of `kcr.`.
- Temporary folder and file prefixes: `capacity-room-` in place of `k8s-capacity-report-` and `kcr-`.
- Compose database and user `capacityroom`; mount `/etc/capacity-room`; the operator's file `capacity-room.env`.
- Colophon en: `Generated by CapacityRoom from a snapshot of Prometheus-compatible metrics. Issued on {{.Issued}}.`
- Colophon pt-BR: `Gerado pelo CapacityRoom a partir de um snapshot de métricas compatíveis com o Prometheus. Emitido em {{.Issued}}.`
- Unchanged: the advisory lock numbers, River, the schema and every migration, the snapshot and its `schema_version` 2.0, the `graphite-report` package, the names of the original (`kubernetes-report`, `kube_capacity_report`), `report.toml`, `platform.toml`, `profiles.toml` and their keys, `testdata/prometheus/`, `testdata/python/`.
- History is never edited: `docs/superpowers/plans/`, every file of `docs/superpowers/specs/` except `2026-09-27-k8s-capacity-report-design.md`, `docs/decisions/`, `docs/reference/`, and the `CHANGELOG.md` sections of 1.x and earlier.
- Every subagent: never wait on standard input, never write to `/tmp` (scratch goes under `.cache/`), leave no background process, never run Docker, never run `git stash`, `git restore`, `git checkout` of a path, or `git clean`; every commit names its paths (`git add <paths>`).
- Comments say what the code does; no comment names a task, a phase, a step, or a path under `.cache/`.

## Review Focus

- **An old name the guard's pattern misses**, such as `K8sCapacityReport`, `kcr` glued to a word (`kcrVersion`), or `KCR` in a Typst or shell file. A reader expects no old name anywhere live. The adversarial review greps `(?i)kcr` and `capacity.?report` raw over the live paths; Task 5's unit tests pin the joined forms the pattern does catch.
- **An operator who still sets `KCR_DATABASE_DSN` after the upgrade.** `serve` must stop with a message that names `CAPACITYROOM_DATABASE_DSN`, never the old name. Task 2 pins the message in `internal/platform/settings`.
- **The secret scan of `make e2e`.** The database password `capacityroom_e2e_only` is set at one line of the `Makefile` and searched in the logs at another. If only one is renamed, the scan looks for a string no log holds and passes in silence. Task 2 renames both and the main thread checks the e2e log names the new pattern.
- **The test typst switch.** `CAPACITYROOM_TYPST` must reach the worker of `deploy/worker-e2e.Containerfile` and the Compose file, or the recovery spec runs real typst. `make e2e` in the gate proves it.
- **A browser with the old cookie or storage key.** The server reads cookies and the web app reads storage only by the constants, so an old `kcr_session` or `kcr.theme` is never read: the reader signs in again and the default theme applies. Task 2 pins the constants by literal tests, and `make e2e` signs in afresh.

```go
package guard

import (
	"bytes"
	"path"
	"regexp"
	"strings"
)

// oldNamePattern matches a name the project carried before 2.0.0: the
// command k8s-capacity-report, and kcr as a word or a prefix in any case,
// with "_" counted as a separator so that VITE_KCR_VERSION is found.
var oldNamePattern = regexp.MustCompile(`(?i)k8s-capacity-report|(^|[^a-z0-9])kcr([^a-z0-9]|$)`)

// OldNameHistory lists the paths that keep the old names as a record. A
// path ending in "/" covers its folder. The design keeps its file name and
// is not history, so it is named apart in oldNameHistory.
var OldNameHistory = []string{
	"docs/superpowers/plans/",
	"docs/superpowers/specs/",
	"docs/decisions/",
	"docs/reference/",
	"testdata/python/",
	"testdata/prometheus/",
	"internal/guard/oldname.go",
	"internal/guard/oldname_test.go",
}

// livingDesign is the design of the project. It keeps its dated file name,
// so a citation of that name is not an old name, and the file itself is
// read like any living document.
const livingDesign = "docs/superpowers/specs/2026-09-27-k8s-capacity-report-design.md"

func oldNameHistory(rel string) bool {
	if rel == livingDesign {
		return false
	}
	for _, p := range OldNameHistory {
		if rel == p || (strings.HasSuffix(p, "/") && strings.HasPrefix(rel, p)) {
			return true
		}
	}
	return false
}

// OldNameLines returns the 1-based numbers of the lines of content that hold
// an old name. A binary file, one holding a NUL byte, has none. In
// CHANGELOG.md the lines from the first heading of a version below 2.0.0 to
// the end are history and are not read.
func OldNameLines(rel string, content []byte) []int {
	if bytes.IndexByte(content, 0) >= 0 {
		return nil
	}
	var found []int
	for i, line := range strings.Split(string(content), "\n") {
		if rel == "CHANGELOG.md" {
			if m := versionHeadingPattern.FindStringSubmatch(line); m != nil && compareVersions(m[1], "2.0.0") < 0 {
				break
			}
		}
		if oldNamePattern.MatchString(strings.ReplaceAll(line, path.Base(livingDesign), "")) {
			found = append(found, i+1)
		}
	}
	return found
}
```

`compareVersions` (`internal/guard/changelog.go:77`) returns `a - b` on the first differing part, so a version below 2.0.0 compares negative.

The parameter is `rel`, not `path`, so that the package `path` stays usable inside the function.
